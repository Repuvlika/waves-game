# WAVES — Naval Shipyard Tycoon (1850–1940)

A single-file naval shipyard tycoon + warship designer. You run a shipyard from
the age of iron to the age of radar: win state contracts against rival yards,
hire staff, license proven designs on the world market, and unlock each decade
by delivering ships.

Everything lives in **one HTML file** (`app/src/main/assets/game.html`).
This repository wraps it into an Android APK and gives it over-the-air
updates, exactly like a certain aviation designer you may know.

---

## Repository map

```
├─ app/src/main/assets/index.html   boot loader (splash + OTA updater)
├─ app/src/main/assets/game.html    THE GAME — edit this to change the game
├─ app/src/main/java/.../MainActivity.java   WebView shell (~90 lines)
├── app/build.gradle, settings.gradle ...     Android build config
├─ .github/workflows/android.yml    builds a signed APK on every push
├─ VERSION.txt                      game version (bump to push an update)
├─ updates/latest.json              OTA manifest (auto-regenerated by CI)
└─ icon_1024.png                    source icon
```

## First build — phone only, ~15 minutes

1. **Create the repo** — on GitHub (mobile web works): *New repository* →
   name it e.g. `waves-game` → **Public** (required for free Actions + CDN).

2. **Upload everything** — in the repo: *Add file → Upload files*.
   Upload the **contents** of this folder (keep the folder structure:
   you can't drag folders on mobile, so create each folder with
   *Create new file* — typing `app/src/main/AndroidManifest.xml` in the name
   box creates the folders automatically — then upload that file's content
   with the pencil/replace, or paste it). Files that must exist:
   - `app/src/main/AndroidManifest.xml`
   - `app/src/main/java/com/waves/game/MainActivity.java`
   - `app/src/main/assets/index.html`
   - `app/src/main/assets/game.html`
   - `app/build.gradle`, `build.gradle`, `settings.gradle`, `gradle.properties`
   - `.github/workflows/android.yml`
   - `VERSION.txt`, `updates/latest.json`, `README.md`
   - `app/src/main/res/mipmap-mdpi/ic_launcher.png` … (5 icon sizes)
   Tip: uploading the 5 PNG icons is easiest on desktop, or use the GitHub
   mobile app which supports folder uploads.

3. **Point the boot loader at your repo** — open
   `app/src/main/assets/index.html`, press the pencil (✏️), and at the top of
   the script change:
   ```js
   var CFG = {
     OWNER:  'YOUR-USERNAME',   // your GitHub username
     REPO:   'waves-game',      // your repo name
     BRANCH: 'main'
   };
   ```
   Commit the change.

4. **Build the APK** — open the *Actions* tab → the "Build APK & publish
   update" workflow runs automatically (or tap it → *Run workflow*).
   When it goes green, open the run → **Artifacts → WAVES-apk** → download
   the APK.

5. **Install** — open the downloaded APK on your phone (allow "install
   unknown apps" when asked). Done.

The workflow also writes `updates/latest.json` (version + SHA-256 of the
game) back into the repo and caches the signing key, so **every future APK
has the same signature** — reinstalls never lose your save.

## Updating the game later (the OTA part)

1. Edit `app/src/main/assets/game.html` (or upload a new version).
2. Change `VERSION.txt` to the new version (e.g. `1.1.0` — must be **higher**
   than before).
3. Push. CI rebuilds `updates/latest.json` and the APK automatically.

Installed apps will then update themselves by the boot loader rules:

| situation | result |
|---|---|
| remote version **higher** than installed | downloads update, verifies SHA-256, caches it |
| remote version **equal or lower** | keeps the installed copy |
| offline / GitHub unreachable | uses the cached copy, else the bundled one |

No Play Store, no reinstalling, no Android Studio.

## The game itself

- **Designer**: hull, armour, machinery, guns, battery, sensors,
  superstructure, identity — with a live side profile and deck plan that
  redraw as you design. Blueprint PNG export included.
- **Tycoon layer**: contracts (state / export / private), rival yards that
  bid against you, staff (architects, draughtsmen, shipwrights, clerks),
  research RP (R&D tree arrives in a future update), monthly ledger,
  world market licensing.
- **Progression**: 1850s → 1940s, a decade at a time; deliver
  3–5 accepted designs per decade to unlock the next.
- **Saves**: automatic (localStorage) + Export/Import JSON.
- **Currencies**: £ UK · fr. France · $ USA · ₽ Russia · ℳ/Tlr. Germany.
